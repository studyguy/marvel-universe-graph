# 关系体系（Relation System）

> 站内实时版：`/docs/relations`（由 `data/taxonomy.ts` 直接渲染）。当前共 **19 大类 / 95 种关系类型**，均定义方向性、端点约束、视觉权重与子属性 schema。

## 子属性体系

- **通用子属性**（所有关系可携带）：`起始 since`（锚定作品/时间）、`状态 status`（当前/历史）、`来源作品 via`。
- **类型特有子属性**（示例）：
  - 成员：`身份`（创始/正式/前任/荣誉）、`任期`
  - 出场/主演：`身份`（主角/配角/客串/提及）、`饰演`（演员）
  - 持有/使用：`途径`（获得/夺取/赠予/继承/研制）、`时段`
  - 敌对：`首次对立`；对手：`领域`
  - 导致：`直接性`（直接/间接）；击杀：`时间`、`地点`
  - 克隆/变体：`差异宇宙`；共生结合：`时期`
  - 所属频道：`阶段`（如 Phase 1–6）；宇宙碰撞：`碰撞事件`
  - 血缘/养亲/兄弟姐妹：`称谓`

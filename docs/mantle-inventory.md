# 名号体系全量盘点（Mantle Inventory）

> 建模约定：**名号（角色身份）= 可被不同人物担任/继承的角色名**（如"美国队长"）；**人物 = 名号的承担者**（如史蒂夫·罗杰斯、山姆·威尔逊）。
> 名号为独立节点（类型 `mantle`，id `mnt-*`，金色）；人物维持原 `character` 节点，以"担任（held-mantle）"关系连接（人物→名号，反向"由…担任"，子属性：时期/归属宇宙/状态/来源作品）。
> 判定原则：**凡"称号型"角色名（非纯人名）一律建名号**——无论单人专属还是多人共享；纯人名（托尼·斯塔克、灭霸、洛基、卡魔拉、格鲁特…）与种族/组织不建模；演员保持"饰演"子属性。

## 规模
- 名号节点：**93 个**（英雄名号 80 / 反派名号 12 / 职位头衔 1）
- 担任关系：**143 条**，覆盖 MCU / Earth-616 / 福克斯 X 战警 / SSU / 动画 / 游戏全部宇宙

# 数据清单盘点报告（M0）

> 实际交付：**625 节点 / 1116 关系**（超出首批目标 300，处于盘点预估 600~800 区间）

> 原始结论：目标规模锁定为约 660 节点 / 1700+ 关系。以下为按 11 类实体逐一盘点后的制作清单（M1 先做约 320 个，M5 扩充至目标规模）。数据深度优先级：MCU 全量 → 漫画 616 核心 → 其他频道（X 战警电影宇宙 / SSU / 动画 / 游戏 / 老剧）。

## 盘点方法
基于 Marvel Database 与 MCU Wiki 的分类体系（Characters / Teams / Locations / Items / Events / Races / Realities / Comics / Films / Series）逐类清点可词条化的知名实体，交叉核对 2026 年 8 月前已发布的最新内容（已核实：《蜘蛛侠：崭新之日》2026-07-31 已上映；《复仇者联盟：毁灭日》定档 2026-12-18，收录为"即将上映"作品节点）。

## 关系密度预估
- MCU 角色平均 6-8 条关系（出场×作品、成员、人际、因果）；漫画核心角色 4-6 条；
- 作品节点平均 4-6 条（频道归属、设定宇宙、前后作、主演）；
- 事件节点 5-10 条（参与者、因果、地点、宇宙）；
- 预计总关系量 **1700~2000 条**，其中 60% 以上携带子属性（出场身份/饰演、成员身份/任期、持有途径/时段、因果直接性等）。

## 建模决策（写入体系文档）
1. **演员不设独立节点**：作为"出场"关系的 `饰演` 子属性。
2. **跨宇宙同名角色分立节点**：如蜘蛛侠按宇宙分立（MCU 版/马奎尔版/加菲版/616 版），用"多元变体"关系互连——这是频道视图的核心展示点。
3. **MCU 流媒体剧集归 MCU 频道**（同一正史 Earth-199999）；ABC/Netflix 老剧归"电视剧宇宙"频道（正史归属存争议，正史规则字段标注）；福克斯 X 战警与 SSU 归"其他影视宇宙"（子频道标注）。
4. 漫画大事件同时是 `work`（作品）与 `event`（剧情事件）两种节点，用"改编为事件"关系连接。

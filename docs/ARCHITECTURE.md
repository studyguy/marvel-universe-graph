# ARCHITECTURE — 漫威宇宙全维关系图谱

> 本文件是项目的**唯一架构真相源**。任何新会话开始编码前，先读本文件回到已定架构；任何改动先改这里再改代码。

## 1. 项目背景
把漫威全部内容生态（漫画/电影/剧集/动漫/游戏等）建成一张可交互的"节点+关系"知识图谱网站，以"中心放射 + 逐层下钻"的范式浏览宇宙中一切事物的关联。

## 2. 目标用户
漫威粉丝与内容研究者（中英双语用户），PC 与移动端并重。

## 3. 核心需求
1. 单一图底座：全站是同一张"节点+关系"大图，一切视图皆为其投影；
2. 中心放射 + 逐层下钻 + 历史回退，禁止一次性平铺全量节点；
3. 9 种视图模式切换（全景/角色/团队/场景/作品/物品/事件/宇宙/频道）；
4. 节点/关系完整交互：详情面板（含关系子属性）、搜索直达、筛选与图例；
5. 中英双语全站；断网完整可用；状态本地记忆。

## 4. 架构设定
- 产品形态：响应式 Web 静态站（PC + 移动端）。
- 架构模式：纯前端 SPA，"数据管线 → 静态图数据 → 投影式渲染引擎"三层：
  - **数据层**：`data/source/*.ts`（实体声明）→ `scripts/build-data.ts`（校验+汇编）→ `public/data/graph.json`（运行时唯一数据源）；
  - **引擎层**：自研 Canvas 2D 图谱引擎（`src/graph/`），中心放射布局 + 相机 + 命中测试 + 动画；
  - **UI 层**：React 组件（顶栏/筛选/详情/图例/引导/文档页），通过 Zustand store 与引擎单向同步。
- 运行环境：本地 / 任意静态托管；运行时零外网请求。

## 5. 技术约束
| 项 | 选型 | 版本 |
|---|---|---|
| 构建 | Vite | ^5.4 |
| 语言 | TypeScript (strict) | ^5.6 |
| UI | React | ^18.3 |
| 路由 | react-router-dom | ^6.26 |
| 状态 | Zustand（persist 中间件存 localStorage） | ^4.5 |
| 数据脚本 | tsx | ^4.19 |
| 图形库 | **不引入**（Cytoscape/Sigma/D3 均不用），Canvas 2D 自研 | — |

## 6. 非功能需求
- 性能：聚焦投影保证单屏可见节点 ≤ 数百；LOD（远焦隐藏标签）；rAF 单循环渲染；图片懒加载 + 生成式占位头像；中端手机不卡顿；
- 兼容：现代浏览器；移动端无横向滚动、安全区适配、手势不冲突；
- 可靠：加载中/空结果/可重试错误/图片占位四态兜底，永不白屏；
- 合规：数据与图片来源 fandom wiki（CC BY-SA），页脚署名，学习/粉丝用途。

## 7. 实施计划（里程碑，连续交付）
M0 体系盘点与文档 → M1 schema+首批数据 → M2 Canvas 引擎 → M3 核心交互 → M4 全局与多端 → M5 数据充实与验收。详见 README 路线图。

## 8. 输出要求
每模块：代码 + 运行验证（dev/preview + 浏览器实测）+ 必要注释（仅解释代码无法自明的约束）。

## 9. 验收标准
断网完整可浏览；双击下钻/回退；关系子属性可查；9 视图动画切换；搜索直达；双语切换；状态记忆；移动端流畅无横向滚动；页脚署名；体系文档站内可查（/docs/schema、/docs/relations）。

## 10. 限制条件（不做什么）
- 不做后端/账号/UGC 编辑；不引入重型图形库/iframe/SSR；
- 不一次性平铺全量节点；
- 站点运行时零外网请求（`fetch-images` 等仅为本地脚本增强）。

```
  taxonomy.ts    节点分类 + 关系体系 + 视图配置（体系真相源）

  store/         Zustand（含 persist）
  i18n/          UI 双语字典（数据内字段自带 zh/en）
  components/    UI 组件
  pages/         图谱页 / 文档页
docs/            ARCHITECTURE / 节点分类体系 / 关系体系 / 数据盘点
public/data/     生成物 graph.json（勿手改）
```

# 节点分类体系（Node Taxonomy）

> 站内实时版：`/docs/schema`（由 `data/taxonomy.ts` 直接渲染，本文为其静态快照）。
> 基线 10 大类经真实内容校验微调；子类与属性字段依据 Marvel Database / MCU Wiki 的实际词条结构扩充。

## 建模决策

1. **演员不设独立节点**：作为"出场"关系的 `饰演` 子属性，避免图谱爆炸。
2. **跨宇宙同名角色分立节点**：当版本人格/经历显著分化时（如三代电影蜘蛛侠），分立节点并以"多元变体"关系互连；这是频道视图的核心展示点。
3. **MCU 流媒体剧集与特别篇归 MCU 频道**（同一正史 Earth-199999）；ABC/Netflix 老剧归"电视剧宇宙"频道（正史归属官方口径存在分歧，以 `正史规则` 字段标注）；福克斯 X 战警与索尼 SSU 归"其他影视宇宙"。
4. 漫画大事件同时建立 `作品` 与 `事件` 两类节点，以"改编为事件"关系连接。
